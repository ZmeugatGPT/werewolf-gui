# Werewolf GUI

Модуль для Foundry VTT 14 (система **World of Darkness 20th**), который выводит
**иконку текущей формы оборотня под токеном** персонажа на карте.

Под токеном появляется компактная плашка: иконка формы (хомид / глабро /
кринос / хиспо / люпус) и, при желании, её название. Плашка автоматически
обновляется при смене формы, двигается и скрывается вместе с токеном.

---

## Зачем это нужно

В системе `worldofdarkness` механика смены формы реализована, но визуального
индикатора на карте нет:

* старый лист оборотня (`Werewolf` / `Changing Breed`) вызывает
  `TokenHelper.formShift()` — в текущей версии системы эта функция
  **пустая** (в самом начале стоит `return;`), поэтому на канвасе ничего не
  происходит;
* новый лист `PC` создаёт `ActiveEffect`, но его иконка выводится
  **в левом верхнем углу токена**, а не под ним.

Модуль закрывает этот пробел и сознательно **не дублирует** иконки системы:
системная иконка статуса скрывается (настройка «Скрывать системную иконку»).

---

## Несвязанные токены (`actorLink: false`)

**По умолчанию Foundry создаёт несвязанные токены** (`actorLink` у
`PrototypeToken` равен `false`, и система World of Darkness его не переопределяет;
для акторов в этом мире тоже стоит `false`). Такой токен держит собственную копию
данных актора в `TokenDocument.delta`, включая `system.shapes`. Поэтому:

* смена формы с листа, открытого **с токена** — работает (пишется в delta токена);
* смена формы с листа, открытого **из списка персонажей** — пишется в базового
  актора и до токена сама по себе не доходит.

Синхронизация работает **в обе стороны** и включается мировой настройкой
«Синхронизировать форму с несвязанными токенами»:

* **базовый актор → токены.** При изменении `system.shapes` у базового актора
  (лист из списка персонажей) выбранная форма переносится в `delta` всех
  несвязанных токенов этого актора на **всех сценах** (только флаги `isactive`).
  Делает это клиент ГМа, так как только у него есть права писать в токены любых
  сцен.
* **токен → базовый актор.** Когда форма меняется на токене (панель быстрого
  переключения), выбор дублируется и на базового актора — иначе лист, открытый
  из списка персонажей, показывал бы старую форму.

**Рекомендуемый вариант для персонажа игрока — связанный токен.** Тогда форма
хранится на самом акторе, и все токены этого актора на всех сценах показывают
одну и ту же форму автоматически, без какой-либо синхронизации.

Как включить связь:

* для новых токенов — у актора в **Prototype Token** включить
  **Link Actor Data** (в русской локализации — «Связывать данные актора»);
* для уже стоящего токена — правый клик по токену → шестерёнка (Token
  Configuration) → та же галочка;
* сразу для всех токенов актора на всех сценах — из консоли/макроса:
  `await game.modules.get("werewolf-gui").api.linkTokens(actor, true)`.

⚠️ При включении связи Foundry **отбрасывает собственные изменения токена**
(ActorDelta), в том числе правки предметов и форму. Для нового персонажа это
безопасно; для «пожившего» токена — сначала стоит проверить, что в нём нет
нужных правок.

## Как это работает для игроков

* Отрисовка плашки — **клиентская**: любой игрок, который видит токен, видит и
  иконку формы. Скрытые (`hidden`) и «секретные» токены плашку не показывают —
  она наследует видимость токена, потому что является его дочерним объектом.
* Персональные настройки (размер, позиция, подпись, прозрачность, «только
  доступные акторы») — клиентские: каждый настраивает под себя.
  Синхронизация формы — **мировая** настройка, её меняет только ГМ.
* Игрок, владеющий персонажем, может сам менять форму:
  * **связанный** токен — обновляется базовый актор, плашка меняется у всех;
  * **несвязанный** токен — правка уходит в `delta` токена, плашка тоже
    обновляется у всех.
* Со **связанными** токенами никакой синхронизации не требуется: форма лежит на
  акторе, и все токены этого актора на всех сценах показывают её одинаково.
  Синхронизация ниже нужна только для несвязанных токенов.
* Если игрок меняет форму **панелью** на несвязанном токене, выбор дублируется
  на базового актора, поэтому лист персонажа (из списка) и остальные токены
  тоже обновляются.
* Если игрок меняет форму с листа **базового актора** (из списка персонажей),
  перенос формы в несвязанные токены выполняет **клиент ГМа** (только у него
  есть права писать в токены любых сцен). Если ГМ не в сети, синхронизация не
  произойдёт — сама смена формы при этом сохранится.
* Системную иконку-эффект скрывает тот клиент, у которого есть права на эффект
  (владелец персонажа или ГМ); ГМ дополнительно прячет уже существующие эффекты
  при входе в мир.

## Возможности

* Поддержка **обоих** форматов данных системы:
  * старые листы — `actor.system.shapes` (ключи `homid`, `glabro`, `crinos`,
    `hispo`, `lupus`), включая сменные виды (Changing Breeds);
  * лист `PC` — предметы `Trait` с `system.type === "wod.types.shapeform"`
    и `system.isactive === true`.
* Иконки берутся из ресурсов системы, без копирования ассетов:
  `systems/worldofdarkness/assets/img/werewolf/form/form_<форма>.svg`
  (резервный путь — `.../img/shapes/form_<форма>.svg`).
* Подпись формы локализуется через ключи системы `wod.shapes.*`
  (поддерживается русская локализация модуля `ru-ru`).
* **Панель быстрого переключения форм** — небольшое перемещаемое окно с
  кнопками форм текущего актора (см. ниже). Работает для игроков: цель
  берётся с выбранного токена или из назначенного персонажа.
* Настройки на клиент (Foundry → Настройки → Настройки модулей):
  размер, позиция, прозрачность, показ подписи, скрытие в форме хомид,
  скрытие системной иконки, панель форм.
* Публичное API для макросов: `game.modules.get("werewolf-gui").api`.

## Установка

Модуль уже развёрнут в `Data/modules/werewolf-gui`. Достаточно включить его в
списке модулей мира. Требуется система `worldofdarkness` (проверено на 7.3.1)
и ядро Foundry 14.

## Панель быстрого переключения форм

Небольшое окно-панель с кнопками форм: одна кнопка на форму, активная
подсвечена, у каждой иконка из ресурсов системы и подпись (отключается).
Клик переключает форму — так же, как это делает лист.

* **Цель панели:** выбранный (controlled) токен, если его актор — оборотень;
  иначе назначенный персонаж пользователя (`game.user.character`). Если
  подходящего актора нет или нет прав — панель скрывается.
* **Перемещение:** окно таскается за заголовок; позиция запоминается отдельно
  для каждого пользователя (клиентская настройка `formBarPosition`).
* **Показать/скрыть:** крестик на панели выключает настройку «Показывать
  панель форм»; включить обратно можно галочкой в настройках модуля или
  горячей клавишей **G** (меняется в Configure Controls → Werewolf GUI).
* **Права:** если у пользователя нет прав на актора, панель не показывается;
  кнопки дополнительно блокируются.
* Переключение выполняется напрямую (как активация формы в листе оборотня):
  обновляются `system.shapes` и связанные бонусы (старые листы) либо
  предметы-формы `wod.types.shapeform` (лист PC), после чего система
  пересчитывает тоталы. Для PC-персонажей не-оборотней (сменные виды)
  системный бросок на смену формы не запрашивается.

## API

```js
const api = game.modules.get("werewolf-gui").api;

// Текущая форма актора: { key, icon, label, source } | null
api.getActiveForm(actor);

// Принудительно перерисовать плашки.
api.refresh();

// Перерисовать только токены конкретного актора.
api.refreshActor(actor);

// Включить/выключить "Link Actor Data" у всех токенов актора на всех сценах.
// Только ГМ. ВНИМАНИЕ: при включении Foundry отбрасывает собственные
// изменения токенов (ActorDelta) - вызывать осознанно.
await api.linkTokens(actor, true);

// Панель быстрого переключения форм.
await api.showFormBar();
await api.hideFormBar();
await api.toggleFormBar();
```

## Как это устроено

Плашка — это `PIXI.Container`, который добавляется **дочерним объектом к
placeable токена** (`token.addChild(...)`). Благодаря этому он сам следует за
токеном при перемещении, вращении, скрытии и изменении прозрачности, а нам
остаётся только пересчитывать его геометрию.

Хуки, на которые подписан модуль:

| Хук | Назначение |
| --- | --- |
| `canvasReady` | создать плашки для всех токенов сцены |
| `drawToken` | создать плашку для нового токена |
| `refreshToken` | пересчитать размер/позицию при обновлении токена |
| `destroyToken` | убрать плашку |
| `controlToken` | переключить панель форм на выбранного актора |
| `updateToken` | реакция на скрытие/смену текстуры/размера |
| `updateActor` | реакция на смену `system.shapes` и синхронизация формы с несвязанными токенами |
| `createItem` / `updateItem` / `deleteItem` | реакция на переключение предмета-формы у актора `PC` |
| `createActiveEffect` / `updateActiveEffect` / `deleteActiveEffect` | синхронизация с системными эффектами |

Зависимости от системы (намеренные, чтобы не дублировать ассеты):

* структура данных `actor.system.shapes` и `Trait`-предметов
  `wod.types.shapeform`;
* ресурсы `assets/img/werewolf/form/*.svg` (и дубли `assets/img/shapes/*.svg`);
* ключи локализации `wod.shapes.*`;
* служебные эффекты системы с `flags.worldofdarkness.shapeformIcon`.

Если система поменяет какие-то из этих путей или полей, достаточно поправить
`scripts/forms.js` и (при необходимости) блок совместимости в `scripts/main.js`.
